# Система за контрол на качеството

Приложение за отчитане на контролни данни от отдел качество за всеки асортимент.

## Структура на проекта

```
/Database/
├── 01_CreateDatabase.sql          # Създаване на база данни
├── 02_CreateBaseTables.sql        # Основни таблици (складове, асортименти, части)
├── 03_CreateQualityTables.sql     # Таблици за качествен контрол
├── 04_CreateIndexes.sql           # Индекси за оптимизация
├── 05_CreateViews.sql             # Изгледи за лесен достъп
├── 06_CreateFunctionsAndProcedures.sql # Функции и процедури
├── 07_SampleData.sql              # Примерни данни
├── 08_SampleQueries.sql           # Примерни заявки
├── InstallDatabase.sql            # Пълна инсталация
└── README.md                      # Документация
```

## Възможности на системата

### ✅ Основни функционалности
- Управление на асортименти по складове
- Дефиниране на граници за тегло на парчета
- Поддръжка на многокомпонентни асортименти (напр. горно/долно бутче)
- Процес на мариноване с проследяване на рандеман
- Автоматично коригиране на тегла извън границите
- Запазване на реални измерени стойности

### ✅ Качествен контрол
- Създаване на партиди за всеки асортимент
- Тестване на пакети (до 4 теста на пакет)
- Измерване на отделни парчета и цели пакети
- Проверка дали теглата са в зададените граници
- Следене на операторите, извършващи тестовете

### ✅ Отчетност
- Дневни отчети по складове и асортименти
- Месечни статистики за качество
- Операторски отчети за точност
- Анализ на рандемана при мариноване
- Проследяване на корекции и причините за тях

## Бърз старт

1. **Инсталация на базата данни:**
   ```sql
   sqlcmd -S server_name -i "Database/InstallDatabase.sql"
   ```

2. **Добавяне на примерни данни (опционално):**
   ```sql
   sqlcmd -S server_name -i "Database/07_SampleData.sql"
   ```

3. **Тестване със примерни заявки:**
   ```sql
   sqlcmd -S server_name -i "Database/08_SampleQueries.sql"
   ```

## Системни изисквания

- SQL Server 2012 или по-нова версия
- Минимум 100MB свободно място за база данни
- Права за създаване на база данни и таблици

## Архитектура

### Ключови таблици:
- **Warehouses** - Складове
- **Assortments** - Асортименти с техните характеристики
- **WeightBoundaries** - Граници за тегло
- **QualityTests** - Тестове на качество
- **WeightMeasurements** - Измервания на отделни парчета
- **MarinationData** - Данни за процеса на мариноване

### Основен процес:
1. Дефиниране на асортимент с граници за тегло
2. Създаване на партида за деня
3. Тестване на пакети от партидата
4. Измерване на парчета и записване в системата
5. Автоматично коригиране при нужда
6. Генериране на отчети и чек карти

За подробна документация вижте `Database/README.md`.
