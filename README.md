# YaldazVacheva - E-commerce Database Schema

Тази репозитория съдържа пълнофункционална SQL схема за електронна търговия (e-commerce) база данни.

## 📁 Файлове

- **`database_schema.sql`** - Основният SQL скрипт за създаване на базата данни (534 реда)
- **`test_database.sql`** - Тестови заявки за проверка на функционалността (127 реда)  
- **`DATABASE_README.md`** - Подробна документация на схемата
- **`SCHEMA_DIAGRAM.md`** - Визуална диаграма на връзките между таблиците
- **`INSTALLATION_GUIDE.md`** - Ръководство за инсталация и настройка

## 🚀 Бързо стартиране

```bash
# Стартиране на MySQL
mysql -u root -p

# Изпълняване на скрипта
source database_schema.sql

# Тестване
source test_database.sql
```

## 🗄️ Особености на базата данни

- **12 таблици** - users, products, orders, categories, reviews, и др.
- **4 тригера** - Автоматично обновяване на рейтинги и цени
- **2 view-та** - За оптимизирани заявки  
- **2 процедури** - За количка и поръчки
- **Пълна индексация** - За оптимална производителност
- **UTF-8 поддръжка** - За български език
