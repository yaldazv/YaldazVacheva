# Database Schema Documentation

## Описание на базата данни

Тази база данни е създадена за e-commerce система и съдържа всички необходими таблици за пълнофункционален онлайн магазин.

## Структура на базата данни

### Основни таблици:

1. **users** - Потребители на системата
2. **addresses** - Адреси на потребителите (за доставка и фактуриране)
3. **categories** - Категории продукти (поддържа йерархия)
4. **products** - Продукти в магазина
5. **product_images** - Изображения на продуктите
6. **orders** - Поръчки
7. **order_items** - Елементи в поръчките
8. **shopping_cart** - Количка за пазаруване
9. **reviews** - Отзиви за продукти
10. **coupons** - Купони за отстъпка
11. **coupon_usage** - Използване на купони
12. **wishlist** - Списък с желания

## Ключови особености:

### Връзки между таблиците:
- **users** → **addresses** (1:N)
- **users** → **orders** (1:N)
- **users** → **shopping_cart** (1:N)
- **users** → **reviews** (1:N)
- **users** → **wishlist** (1:N)
- **categories** → **products** (1:N)
- **categories** → **categories** (самореферентна за подкатегории)
- **products** → **product_images** (1:N)
- **products** → **order_items** (1:N)
- **products** → **shopping_cart** (1:N)
- **products** → **reviews** (1:N)
- **orders** → **order_items** (1:N)
- **coupons** → **coupon_usage** (1:N)

### Индекси за производителност:
- Всички първични ключове
- Външните ключове
- Полета за търсене (име, email, SKU)
- Полета за филтриране (статус, активност, дати)
- Композитни индекси за често използвани заявки

### Тригери:
- Автоматично обновяване на рейтинга на продуктите при добавяне/редактиране на отзиви
- Автоматично изчисляване на общата цена в order_items

### View-та:
- **active_products_with_category** - Активни продукти с информация за категорията
- **orders_with_user_details** - Поръчки с детайли за потребителя

### Процедури:
- **AddToCart** - Добавяне на продукт в количката
- **CreateOrderFromCart** - Създаване на поръчка от количката

## Как да използвате скрипта:

1. Стартирайте MySQL сървър
2. Изпълнете скрипта `database_schema.sql`
3. Базата данни `ecommerce_db` ще бъде създадена с всички таблици, индекси, тригери и примерни данни

## Примерни заявки:

```sql
-- Вземане на всички активни продукти с техните категории
SELECT * FROM active_products_with_category;

-- Вземане на всички поръчки за конкретен потребител
SELECT * FROM orders_with_user_details WHERE username = 'ivan_petrov';

-- Добавяне на продукт в количката
CALL AddToCart(1, 1, 2);

-- Създаване на поръчка от количката
CALL CreateOrderFromCart(1, 'credit_card', 1, 1, @order_id);
```

## Забележки:

- Всички текстови полета използват UTF-8 кодиране за поддръжка на български език
- Паролите се съхраняват като hash-ове
- Цените са в BGN (български лева)
- Системата поддържа множество адреси на потребител
- Поддържа се йерархия на категориите
- Системата включва пълнофункционална количка за пазаруване
- Има система за отзиви и рейтинги
- Поддържа се система за купони и отстъпки
