# Документация на база данни за контрол на качеството

## Преглед
Тази база данни е проектирана за система за отчитане на контролни данни от отдел качество за всеки асортимент. Системата поддържа SQL Server 2012/2014 и управлява процеса на качествен контрол на пакетирани хранителни продукти.

## Основни функционалности

### 1. Управление на асортименти
- Поддържа различни типове асортименти (обикновени, мариновани, многокомпонентни)
- Дефинира брой парчета в пакет и граници за тегло
- Организира асортиментите по складове

### 2. Качествен контрол
- Записва тестове на качество (обикновено 4 теста на пакет)
- Измерва тегло на отделни парчета и цели пакети
- Автоматично коригира тегла извън границите
- Запазва реалните измерени стойности

### 3. Процес на мариноване
- Следи тегло преди и след мариноване
- Изчислява рандеман автоматично
- Проверява дали рандемана е в допустимите граници

### 4. Отчетност
- Генерира чек карти за всеки асортимент
- Предоставя дневни, месечни и операторски отчети
- Следи статистики за качество

## Структура на базата данни

### Основни таблици

#### Warehouses (Складове)
- **WarehouseID** - Уникален идентификатор
- **WarehouseName** - Име на склада
- **WarehouseCode** - Код на склада
- **Address** - Адрес

#### Assortments (Асортименти)
- **AssortmentID** - Уникален идентификатор
- **AssortmentName** - Име на асортимента
- **AssortmentCode** - Код на асортимента
- **PiecesPerPackage** - Брой парчета в пакет
- **IsMarinated** - Дали е маринован
- **HasMultipleParts** - Дали има множество части
- **WarehouseID** - Връзка към склад

#### AssortmentParts (Части на асортимент)
- **PartID** - Уникален идентификатор
- **AssortmentID** - Връзка към асортимент
- **PartName** - Име на частта (напр. "Горно бутче")
- **PiecesPerPart** - Брой парчета в частта

#### WeightBoundaries (Граници на тегло)
- **BoundaryID** - Уникален идентификатор
- **AssortmentID** - Връзка към асортимент
- **PartID** - Връзка към част (NULL за цял асортимент)
- **MinWeight** - Минимално тегло
- **MaxWeight** - Максимално тегло
- **TargetWeight** - Целево тегло

### Таблици за тестване

#### Batches (Партиди)
- **BatchID** - Уникален идентификатор
- **BatchNumber** - Номер на партида
- **AssortmentID** - Връзка към асортимент
- **ProductionDate** - Дата на производство

#### TestPackages (Тестови пакети)
- **PackageID** - Уникален идентификатор
- **PackageNumber** - Номер на пакет
- **BatchID** - Връзка към партида
- **PackageWeight** - Тегло на пакета (коригирано)
- **OriginalPackageWeight** - Реално тегло на пакета

#### QualityTests (Тестове за качество)
- **TestID** - Уникален идентификатор
- **PackageID** - Връзка към пакет
- **TestNumber** - Номер на тест (1-4)
- **OperatorName** - Име на оператор
- **TotalWeight** - Общо тегло (коригирано)
- **OriginalTotalWeight** - Реално общо тегло

#### WeightMeasurements (Измервания на тегло)
- **MeasurementID** - Уникален идентификатор
- **TestID** - Връзка към тест
- **PartID** - Връзка към част
- **PieceNumber** - Номер на парче
- **MeasuredWeight** - Измерено тегло (коригирано)
- **OriginalWeight** - Реално измерено тегло
- **AdjustedWeight** - Коригирано тегло
- **IsWithinBoundaries** - Дали е в границите
- **WasAdjusted** - Дали е коригирано

#### MarinationData (Данни за мариноване)
- **MarinationID** - Уникален идентификатор
- **TestID** - Връзка към тест
- **SampleSize** - Размер на пробата (обикновено 50)
- **WeightBeforeMarination** - Тегло преди мариноване
- **WeightAfterMarination** - Тегло след мариноване
- **YieldPercentage** - Процент рандеман
- **IsYieldAcceptable** - Дали рандемана е приемлив

### 2. Добавяне на нов тест
```sql
DECLARE @TestID int;
EXEC dbo.sp_CreateQualityTest 
    @PackageID = 1,
    @TestNumber = 1,
    @OperatorName = 'Иван Петров',
    @TotalPieces = 10,
    @TestID = @TestID OUTPUT;
```

### 3. Добавяне на измерване
```sql
EXEC dbo.sp_AddWeightMeasurement
    @TestID = 1,
    @PartID = NULL,
    @PieceNumber = 1,
    @OriginalWeight = 98.5;
```

### 4. Генериране на отчети
```sql
-- Дневен отчет
SELECT * FROM dbo.vw_DailyReports 
WHERE TestDate = '2024-01-01';

-- Измервания с корекции
SELECT * FROM dbo.vw_WeightMeasurementDetails 
WHERE WasAdjusted = 1;
```

## Важни забележки

1. **Запазване на реални стойности**: Системата винаги запазва оригиналните измерени стойности в колони с префикс "Original"

2. **Автоматични корекции**: Когато тегло е извън границите, системата автоматично го коригира, но запазва реалната стойност

3. **Партиди**: Всеки ден се създават нови партиди за всеки асортимент

4. **Тестове**: Обикновено се правят по 4 теста на пакет за увеличаване на точността

5. **Мариноване**: За мариновани продукти се следи рандемана освен границите на теглото
